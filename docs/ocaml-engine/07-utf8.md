# M6 — UTF-8

**Goal**: full UTF-8 mode — validity checking with exact error codes, UTF compile/match
paths, case folding via UCD other_case, XCLASS for wide characters, MATCH_INVALID_UTF,
NO_UTF_CHECK, `\C` and NEVER_BACKSLASH_C.

**Gate G6** (verbatim from plan): testinput4 non-\p ranges; UTF-error sections of
testinput10.

**GATE MET 2026-07-09** — testinput10 44/44 (100%, incl. all UTF-error sections and
the MATCH_INVALID_UTF fragment corpus); testinput4 282/617 (every non-\p unit in
scope passes; the remainder is \p/\X/script-run — 08 doc); testinput5 215/419
(same split). Only the differential-fuzz item remains open (rides doc 09's fuzzer).

## Chunks

- [x] utf.ml: decode/encode/step primitives — GETCHAR/GETCHARINC/GETCHARLEN/BACKCHAR
  macro family (pcre2_internal.h + pcre2_intmodedep.h) + ord2utf (pcre2_ord2utf.c:1-120)
- [x] valid_utf.ml: line-by-line port with exact UTF8_ERR1..21 codes + reported offset
  (pcre2_valid_utf.c:1-398); BADUTFOFFSET (−36) checks at match entry ride with the
  driver chunk below (which owns the subject-side validation)
- [x] compile UTF paths: multi-byte literals in parse/compile, class ranges > 255 →
  OP_XCLASS emission with ranges + property slots, caseless expansion via
  ucd.other_case (pcre2_compile.c: UTF arms across check_escape/parse_regex/
  compile_branch; xclass emission in 6500-6810 region). XCL_PROP/XCL_NOTPROP
  producers are \p-dependent and stay loudly deferred to 08-ucp.md
- [x] xclass.ml: runtime extended-class matcher (pcre2_xclass.c:1-308) + OP_XCLASS repeat
  arms in the interpreter (UTF arms of pcre2_match.c:1934-5005). XCL_PROP/XCL_NOTPROP
  runtime items stay loudly deferred to 08-ucp.md (no producer compiles until then)
- [x] match UTF paths: char/charI/not/notI UTF arms, backref caseless folding via
  other_case, OP_ANY/ALLANY multi-byte stepping, lookbehind BACKCHAR walking
  (UTF arms across pcre2_match.c:995-5900). mb.check_subject is a real field; the
  word-boundary and OP_REVERSE arms read it
- [x] driver: UTF validity check on subject (unless NO_UTF_CHECK), MATCH_INVALID_UTF
  start-skip semantics, mid-character BADUTFOFFSET, `\C` OP_ANYBYTE +
  NEVER_BACKSLASH_C/ERR83 (pcre2_match.c:6530-7777 UTF blocks; pcre2_compile.c \C arms).
  Match-UTF chunk: subject validity check + max_lookbehind walk-back +
  BADUTFOFFSET/UTF8_ERR pass-through with match_data startchar (6795-6929), bump-along
  ACROSSCHAR sites. MATCH_INVALID_UTF chunk: skipped_bad_start (6828-6836), the fragment
  validation loop (6889-6928), FRAGMENT_RESTART (7139-7148), the ENDLOOP fragment
  carry-on (7646-7701) with per-fragment NOTBOL/NOTEOL moptions (7502); `\C`/ERR83
  verified oracle-identical (parse.ml already ports ERR83; OP_ANYBYTE agrees in UTF
  and lookbehind cases)
- [ ] fuzz: enable invalid-UTF byte-mutation mode; harness `utf`/`no_utf_check` modifiers
  exercised; re-baseline testinput4/10 sections
